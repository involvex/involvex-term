# Store screenshots

Partner Center requires screenshots **≥ 1366×768**.

Capture from a packaged build (`bun run build:store` sideload if you have a
test cert, or the NSIS build with matching chrome):

1. Split panes + Git footer
2. Settings → Appearance (include High Contrast preset visible)
3. Command palette or OpenCode side-by-side

Save as `shot-1.png`, `shot-2.png`, `shot-3.png` in this folder before the
first Partner Center submission. Do not upscale smaller captures.
