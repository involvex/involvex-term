Privacy Policy

Involvex Term — last updated 26 November 2026

← Back to docs

Summary

Involvex Term is a local desktop terminal. It does not include advertising SDKs, crash analytics, or telemetry that phones home by default. Data stays on your machine unless you opt into optional features that use the network.

Data stored on your device

  • Settings and session — ~/.involvex-term/settings.json and session.json (window size, themes, tabs, shell profiles, hotkeys).
  • Shell memory — recent directories (from OSC 7) and recent commands the app wrote into a pane. Optional clipboard history persist (clipboardPersist, off by default) stores clip text in shell-memory.json.
  • Chromium profile — ~/.involvex-term/electron (Electron userData).
  • Optional plugins — if you enable plugins, files under ~/.involvex-term/plugins run with full local privileges (see Security policy).

Optional network features

  • Settings sync (opt-in) — Device Code login with GitHub stores an OAuth token and gist id in ~/.involvex-term/sync.json so you can push/pull a private settings gist.
  • GitHub Releases auto-update — only for NSIS / AppImage installs from GitHub. Microsoft Store builds update exclusively through the Store and never check GitHub for updates.
  • Links you open — Ctrl+click / context menu opens URLs in your default browser.
  • OpenCode / agent CLIs — if installed, the app may invoke them locally; their own privacy policies apply to any cloud agent traffic they initiate.

Process list

The optional Process Manager can list running processes (name, CPU, memory, path) using OS APIs so you can inspect or end a process. That data is not uploaded.

Children

Involvex Term is a developer tool and is not directed at children under 13.
